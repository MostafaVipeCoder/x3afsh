# قاموس المصطلحات — Xعفش

> كل مصطلح هيتكرر في الوثائق أو في الكلام مع فريق التنفيذ، بشرح بسيط.

| المصطلح | بالإنجليزي | يعني إيه |
|---|---|---|
| **طقم** | Listing | الإعلان الواحد عن قطعة أو مجموعة عفش. هو الوحدة الأساسية في المنصة. |
| **مسودة** | Draft | طقم اتبدأ ومكملش — محفوظ بس مش ظاهر لحد. |
| **معروض** | Published / Active | طقم كامل البيانات وظاهر للكل. |
| **حساب نشط** | Active User | حساب عمل فعل حقيقي (نشر / تعليق / رسالة / تفاوض / اتصال) خلال فترة معينة. |
| **فعل حقيقي** | Meaningful Action | أي حاجة المستخدم يعملها غير مجرد التصفح. |
| **محادثة** | Conversation / Chat | رسايل بين مستخدمين اتنين على طقم معين داخل المنصة. |
| **تفاوض** | Negotiation | المشتري يعرض سعر والبايع يرد، لحد ما يتفقوا أو يرفضوا. |
| **سعر البداية** | Opening Offer | أول سعر المشتري اقترحه. |
| **سعر النهاية** | Final / Agreed Price | السعر اللي اتفقوا عليه في النهاية. |
| **عرض مضاد** | Counter-offer | رد البايع بسعر مختلف بدل القبول أو الرفض. |
| **اتفاق** | Deal | تفاوض انتهى بإن طرف قبل. |
| **التواصل الخارجي** | Off-platform Contact | ضغط "اتصل" أو "واتساب" — المستخدم بيخرج من المنصة يكمل بره. |
| **لوحة التحكم** | Dashboard | الشاشة اللي صاحب المنصة بيشوف فيها الأرقام. |
| **مؤشر** | Metric / KPI | رقم بنقيس بيه حاجة معينة (عدد الحسابات، نسبة الرد...). |
| **الفترة** | Date Range | المدة اللي الرقم بيتحسب عليها (آخر 7 أيام مثلًا). |
| **نسبة التغيير** | Period-over-period Change | الرقم ده زاد ولا قل مقارنة بالفترة اللي قبلها. |
| **درجة الرضا** | CSAT (Customer Satisfaction Score) | نسبة اللي قيّموا تجربتهم 4 أو 5 من 5. |
| **حدث** | Event | تسجيل إن المستخدم عمل فعل معين (ضغط زرار، فتح صفحة...). أساس كل التحليلات. |
| **خطة التتبّع** | Tracking Plan | قائمة كل الأحداث اللي هنسجلها وإيه المعلومات اللي بتتسجل مع كل واحد. |
| **قمع** | Funnel | سلسلة خطوات بنشوف كام واحد كمّل كل خطوة وكام واحد وقع. |
| **تسرب** | Drop-off | الناس اللي وقفوا عند خطوة ومكملوش. |
| **الاحتفاظ** | Retention | نسبة الناس اللي بترجع تستخدم المنصة بعد أول مرة. |
| **فوج** | Cohort | مجموعة مستخدمين اشتركوا في نفس الفترة، بنتابعهم مع بعض. |
| **خريطة حرارة** | Heatmap | صورة للصفحة بتوضح الناس بتضغط فين أكتر. |
| **تسجيل جلسة** | Session Replay | فيديو لتجربة مستخدم حقيقي على الموقع (من غير بياناته الشخصية). |
| **استبيان** | Survey | سؤال قصير بيظهر للمستخدم داخل المنصة. |
| **استبيان ما بعد التواصل** | Post-contact Follow-up | الأسئلة اللي بنسألها للمستخدم لما يرجع بعد ما ضغط واتساب/اتصل: البيعة تمت؟ بكام؟ ليه لأ؟ |
| **بيعة مُبلّغ عنها** | Self-reported Sale | بيعة المستخدم قال إنها تمت. مش مؤكدة من المنصة، بس أقرب حاجة عندنا للحقيقة. |
| **نسبة إتمام البيع** | Conversion to Sale | من اللي تواصلوا، كام % قالوا إنهم اشتروا. |
| **التكلفة الكاملة** | Total Cost of Purchase | سعر الشراء + النقل والتركيب + مصاريف التحسين بعد الشراء. |
| **إنذار ثقة** | Trust Flag | إجابة بتشير لمشكلة في بايع (مبالغ مش متفقة / حالة أسوأ من الصور / مش محترم). |
| **بلاغ** | Report / Flag | المستخدم بيقول إن فيه إعلان أو تعليق مش مناسب. |
| **مشرف** | Moderator | شخص بيراجع البلاغات ويقرر يشيل ولا يسيب. |
| **تأكيد الموبايل** | OTP / Phone Verification | كود بيتبعت SMS عشان نتأكد إن الرقم حقيقي. |
| **متجاوب** | Responsive | الموقع بيظبط نفسه على شاشة الموبايل والكمبيوتر. |
| **النسخة الأولى** | MVP (Minimum Viable Product) | أصغر نسخة من المنصة تشتغل وتتجرب مع ناس حقيقيين. |
