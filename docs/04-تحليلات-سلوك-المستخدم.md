# تحليلات سلوك المستخدم — Xعفش

> **الحالة:** مسودة للمراجعة
> **السؤال اللي بنجاوب عليه:** إزاي نفهم المستخدم بيعمل إيه على المنصة، وبيقف فين، وليه، عشان نحسّن تجربته؟

---

## 1. الفكرة ببساطة

الداشبورد (ملف 03) بيقولك **"إيه اللي حصل"** — كام حساب، كام طقم.
التحليلات السلوكية بتقولك **"إزاي وليه حصل"** — المستخدم مشي في أنهي طريق، وقف فين، رجع ولا لأ.

الطريقة الأساسية إننا نسجّل **كل فعل مهم** المستخدم بيعمله كـ"حدث" (Event)، بعدين نحلل الأحداث دي بأربع طرق:

| الطريقة | بتجاوب على | مثال |
|---|---|---|
| **القمع (Funnel)** | الناس بتقع فين في رحلة معينة؟ | 100 واحد ضغطوا "اعرض طقم"، 40 بس كملوا للنشر. فين الـ60 راحوا؟ |
| **الاحتفاظ (Retention)** | الناس بترجع بعد أول زيارة؟ | من اللي عملوا حساب الأسبوع ده، كام % رجعوا الأسبوع الجاي؟ |
| **خريطة الحرارة والتسجيل (Heatmap / Session Replay)** | المستخدم بيضغط فين وبيتلخبط فين؟ | فيديو حقيقي لمستخدم بيحاول يرفع صور ومش عارف. |
| **السؤال المباشر (Surveys)** | ليه عمل كده؟ | "ليه مكملتش نشر الطقم؟" |

## 2. الأحداث اللي هنسجّلها (خطة التتبّع)

ده أهم جزء في الملف. كل حدث له اسم، وبيتسجل معاه معلومات إضافية. **الأحداث دي هي اللي كل التحليلات هتتبني عليها**، فلو ناقص حدث هنا، مش هنقدر نحلله بعدين.

### أحداث الحساب
| الحدث | بيتسجل لما | معلومات معاه |
|---|---|---|
| فتح المنصة | المستخدم يدخل الموقع | المصدر (فيسبوك / جوجل / رابط مباشر)، نوع الجهاز |
| بدأ التسجيل | ضغط "اعمل حساب" | |
| أكّد الموبايل | دخّل كود SMS صح | الوقت من بدء التسجيل |
| سجل دخول | | |

### أحداث العرض (البايع)
| الحدث | بيتسجل لما | معلومات معاه |
|---|---|---|
| ضغط "اعرض طقم" | | |
| كتب الوصف | خرج من خانة الوصف | عدد الحروف |
| رفع صورة | كل صورة | رقم الصورة (1، 2، 3...) |
| فشل رفع صورة | | سبب الفشل (حجم كبير / نوع غلط) |
| كتب السعر | | السعر |
| حاول ينشر وفشل | ضغط نشر والبيانات ناقصة | **إيه الناقص** (وصف / صور / سعر) |
| نشر الطقم | | التصنيف، المحافظة، السعر، عدد الصور |
| علّم "اتباع" | | عدد الأيام من النشر |
| سيب المسودة | خرج من غير ما ينشر | آخر خطوة وصلها |

### أحداث التصفح (المشتري)
| الحدث | بيتسجل لما | معلومات معاه |
|---|---|---|
| شاف قائمة الأطقم | | الفلاتر المستخدمة |
| استخدم فلتر | | نوع الفلتر وقيمته |
| بحث | | كلمة البحث، **عدد النتائج** (لو صفر ده مهم جدًا) |
| فتح طقم | | رقم الطقم، جاي منين (قائمة / بحث / رابط) |
| قلّب في الصور | | عدد الصور اللي شافها |
| حفظ في المفضلة | | |

### أحداث التفاعل
| الحدث | بيتسجل لما | معلومات معاه |
|---|---|---|
| بدأ يكتب تعليق | ضغط على خانة التعليق | |
| حاول يقيّم وفشل | التعليق أقل من 15 حرف | عدد الحروف اللي كتبها |
| نشر تعليق/تقييم | | عدد النجوم، طول التعليق |
| بدأ تفاوض | | سعر الطقم، سعر البداية |
| رد على تفاوض | | نوع الرد (قبول / رفض / عرض مضاد)، السعر |
| انتهى تفاوض | | النتيجة، عدد الردود، المدة |
| فتح محادثة | | |
| بعت رسالة | | أول رسالة ولا لأ |
| ضغط "اتصل" | | من فين (صفحة الطقم / المحادثة) |
| ضغط "واتساب" | | من فين |
| جاوب على سؤال الرضا | | الدرجة، بعد أنهي فعل |
| تخطّى سؤال الرضا | | |

### أحداث استبيان ما بعد التواصل (أُضيف 12 أكتوبر)
| الحدث | بيتسجل لما | معلومات معاه |
|---|---|---|
| ظهر استبيان ما بعد التواصل | | رقم الطقم، المرة الكام (1/2/3)، الأيام من الضغطة |
| جاوب السؤال الأول | | أيوه / لأ / لسه |
| كمّل خطوة في الاستبيان | كل سؤال | رقم السؤال، الإجابة (الأرقام والاختيارات بس — النص الحر بيتحفظ منفصل) |
| خرج من الاستبيان | قفله قبل الآخر | عند أنهي سؤال |
| خلّص الاستبيان | وصل للآخر | المسار (اشترى / ماشتراش)، المدة بالثواني |
| انتهى بـ"مجهول" | عدى 14 يوم بدون إجابة | عدد المرات اللي اتسأل فيها |

> **ملاحظة خصوصية:** مش بنسجل محتوى الرسايل ولا أرقام الموبايل في التحليلات. بنسجل إن "رسالة اتبعتت" مش "الرسالة بتقول إيه".

## 3. القمع (Funnels) اللي هنتابعها

### قمع 1: من الزيارة للحساب
```
فتح المنصة → ضغط "اعمل حساب" → أكّد الموبايل
```
**بيقولك:** التسجيل سهل ولا الناس بتهرب منه؟

### قمع 2: من النية للنشر (أهم قمع)
```
ضغط "اعرض طقم" → كتب وصف → رفع صورة 1 → رفع صورة 3 → كتب سعر → نشر
```
**بيقولك:** شرط الـ3 صور بيخلي الناس تسيب الصفحة؟ لو 50% بيقفوا عند الصورة التالتة يبقى لازم نسهّل الرفع أو نراجع الشرط.

### قمع 3: من المشاهدة للتواصل
```
فتح طقم → (تعليق / تفاوض / محادثة) → ضغط اتصل أو واتساب
```
**بيقولك:** الناس بتتفرج وبس ولا بتتواصل؟ وأنهي طريق أكتر — التفاوض ولا المحادثة ولا الاتصال المباشر؟

### قمع 4: التفاوض
```
بدأ تفاوض → البايع رد → اتفاق
```
**بيقولك:** البايعين بيردوا؟ والتفاوض بيوصل لحاجة؟

### قمع 5: التقييم
```
بدأ يكتب تعليق → حاول يقيّم وفشل (أقل من 15 حرف) → نشر
```
**بيقولك:** شرط الـ15 حرف بيمنع تقييمات كتير؟

### قمع 6: من التواصل للبيع الفعلي (أُضيف 12 أكتوبر)
```
ضغط واتساب/اتصل → رجع للمنصة → ظهر الاستبيان → جاوب → "أيوه اشتريته"
```
**بيقولك:** من كل 100 واحد تواصلوا، كام واحد اشترى فعلًا؟ وكمان: كام واحد رجع أصلًا بعد ما ضغط واتساب؟ لو الناس مش بترجع، يبقى المنصة بتتستخدم مرة واحدة وده مؤشر خطير.

### قمع 7: إكمال الاستبيان نفسه
```
ظهر الاستبيان → جاوب السؤال الأول → وصل لنص الاستبيان → خلّصه
```
**بيقولك:** الاستبيان طويل والناس بتزهق منه؟ لو أغلب التسرب عند سؤال معين، نشيله أو نخليه اختياري.

## 4. الاحتفاظ (Retention)

**السؤال:** الناس بترجع؟

هنقيس: من كل الحسابات اللي اتعملت في أسبوع معين، كام % رجعوا وعملوا "فعل حقيقي" في الأسبوع التاني، التالت، الرابع؟

| أسبوع التسجيل | عدد الحسابات | رجعوا أسبوع 1 | أسبوع 2 | أسبوع 3 | أسبوع 4 |
|---|---|---|---|---|---|
| 1 أكتوبر | 100 | 40% | 25% | 20% | 18% |
| 8 أكتوبر | 120 | 45% | 30% | ... | |

ده اسمه **جدول الأفواج (Cohort Table)**. لو الأرقام بتثبت عند رقم معين (مثلًا 18%) ده كويس — معناه فيه ناس بتفضل. لو بتنزل لصفر، المنصة "دلو مخروم".

**تقسيمة مهمة:** هنفصل الاحتفاظ لـ**بايعين** (نشروا طقم) و**مشترين** (متواصلوش غير كمشترين). غالبًا سلوكهم مختلف.

## 5. خرائط الحرارة وتسجيل الجلسات

دي أدوات جاهزة بتتركب على الموقع وبتوريك:
- **خريطة حرارة:** فين الناس بتضغط أكتر على كل صفحة. لو بيضغطوا على حاجة مش زرار، يبقى التصميم بيلخبطهم.
- **تسجيل الجلسة:** فيديو (بدون بيانات شخصية) لتجربة مستخدم حقيقي.

**متى تستخدمها؟** لما القمع يقولك "الناس بتقع عند خطوة X" وأنت مش فاهم ليه — تفتح 10 تسجيلات لناس وقعوا عند X وهتفهم في 20 دقيقة.

## 6. الأسئلة المباشرة (Surveys)

| السؤال | يظهر لمين وإمتى | الهدف |
|---|---|---|
| "ليه مكملتش؟" (اختيارات: الصور صعبة / مش عارف أحط سعر / هرجع بعدين / غير ذلك) | اللي ساب مسودة وخرج | نعرف سبب التسرب في النشر |
| "عرفت تلاقي اللي بتدور عليه؟" (أيوه / لأ) | بعد 3 بحثات من غير فتح طقم | نعرف لو البحث ضعيف |
| سؤال الرضا (ملف 02 — قاعدة G1) | في زيارة لاحقة بعد تجربة تواصل حقيقية، أو بعد أسبوع من النشر من غير تواصل | قياس الرضا العام |
| "إيه اللي ينقص المنصة؟" (نص حر) | مرة واحدة بعد 14 يوم من التسجيل | أفكار للتطوير |
| **استبيان ما بعد التواصل** (ملف 02 — قسم ز) | أول رجوع بعد 24 ساعة من ضغط واتساب/اتصل | هل البيعة تمت، بكام، التكاليف، حالة المنتج، فايدة المنصة، وأسباب عدم الإتمام — **أغنى مصدر بيانات عندنا** |
| استبيان البايع القصير | لما يعلّم "اتباع" | سعر البيع من الطرف التاني + تجربة البايع |

## 7. الأدوات المقترحة

| الأداة | بتعمل إيه | التكلفة | التوصية |
|---|---|---|---|
| **PostHog** | أحداث + قمع + احتفاظ + خرائط حرارة + تسجيل جلسات + أسئلة — **كله في مكان واحد** | مجاني لحد مليون حدث شهريًا | ✅ **الاختيار الأول** — بيغطي كل اللي فوق بأداة واحدة |
| Mixpanel | أحداث + قمع + احتفاظ | مجاني لحد حد معين | بديل كويس بس من غير تسجيل جلسات |
| Google Analytics 4 | إحصائيات زيارات عامة | مجاني | مش كفاية لوحده — بيقيس الزيارات مش السلوك |
| Hotjar | خرائط حرارة + تسجيل جلسات | مجاني محدود | مش محتاجينه لو استخدمنا PostHog |

**التوصية:** نبدأ بـ PostHog لأنه بيجمع كل حاجة، ومجاني للحجم اللي هنبدأ بيه، ولو احتجنا نغيّر بعدين الأحداث اللي سجلناها ممكن تتنقل.

## 8. إزاي هتستخدم كل ده عمليًا؟ (روتين مقترح)

| كل | تعمل إيه |
|---|---|
| **يوم** | بص على الداشبورد (ملف 03) — 5 دقايق. فيه رقم شاذ؟ |
| **أسبوع** | راجع القمع الخمسة. أنهي خطوة فيها أكبر تسرب؟ دي أولويتك الأسبوع الجاي. |
| **أسبوع** | اقرأ آخر 20 تعليق رضا نصي. |
| **أسبوعين** | اتفرج على 5 تسجيلات جلسات لمستخدمين وقعوا في أكبر تسرب. |
| **شهر** | راجع جدول الاحتفاظ. الناس بترجع أكتر ولا أقل من الشهر اللي فات؟ |
| **شهر** | قرر تجربة تحسين واحدة (مثلًا: تسهيل رفع الصور) وقيس أثرها الشهر الجاي بنفس القمع. |

## 9. مؤشرات صحة التجربة (اللي هتعرف منها إن التجربة بتتحسن)

| المؤشر | التعريف | الهدف المبدئي |
|---|---|---|
| نسبة إكمال النشر | نشر ÷ ضغط "اعرض طقم" | أعلى من 50% |
| الوقت لأول نشر | من التسجيل لأول طقم منشور | أقل من 10 دقايق |
| نسبة التواصل | ضغط اتصل/واتساب/محادثة ÷ فتح طقم | أعلى من 10% |
| نسبة بحث بدون نتائج | بحث بصفر نتائج ÷ كل البحثات | أقل من 15% |
| احتفاظ الأسبوع الرابع | راجع القسم 4 | أعلى من 15% |
| نسبة رد البايع في 24 ساعة | محادثات/تفاوضات اتردت خلال يوم ÷ الكل | أعلى من 60% |
| نسبة إتمام البيع (مُبلّغ عنها) | "اشتريته" ÷ (اشتريته + متمتش) | أعلى من 25% |
| نسبة الإجابة على استبيان ما بعد التواصل | جاوبوا ÷ اتسألوا | أعلى من 30% |
| نسبة المبالغ غير المتفق عليها | من اللي اشتروا | أقل من 5% |

الأهداف دي **تخمين مبدئي** — بعد أول شهر بيانات حقيقية هنعدّلها.
