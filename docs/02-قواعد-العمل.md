# قواعد العمل — Xعفش

> **الحالة:** مسودة للمراجعة
> دي القواعد اللي المنصة هتفرضها تلقائيًا. كل قاعدة ليها رقم عشان نقدر نرجعلها بسهولة.

---

## أ. قواعد الحساب

| الرقم | القاعدة |
|---|---|
| A1 | التسجيل برقم موبايل مصري + اسم + كلمة سر. رقم الموبايل لازم يتأكد بكود SMS *(قابل للنقاش — راجع القرارات)*. |
| A2 | رقم موبايل واحد = حساب واحد. |
| A3 | كل حساب يقدر يبيع ويشتري. مفيش نوعين حسابات. |
| A4 | المستخدم يقدر يحذف حسابه. لما يحذفه، أطقمه تختفي، بس تعليقاته وتقييماته على أطقم غيره تفضل باسم "مستخدم محذوف". |

## ب. قواعد نشر الطقم

| الرقم | القاعدة |
|---|---|
| B1 | **مينفعش ينشر طقم غير لو البيانات كاملة:** عنوان، وصف، 3 صور على الأقل، سعر، تصنيف، محافظة. |
| B2 | الوصف لازم يكون **30 حرف على الأقل** *(رقم مقترح — عدّله لو عايز)*. |
| B3 | الصور: 3 على الأقل، 8 على الأكثر. المنصة تطلب صراحةً "صورة من الأمام، صورة من الجنب، صورة قريبة للتفاصيل" عشان تضمن زوايا مختلفة. |
| B4 | السعر رقم أكبر من صفر بالجنيه المصري. |
| B5 | لو المستخدم خرج قبل ما يكمّل، الطقم يتحفظ كـ**مسودة** ومش بيظهر لحد. |
| B6 | الطقم ليه 4 حالات: **مسودة** → **معروض** → **اتباع** أو **مخفي**. |
| B7 | البايع يقدر يعدّل طقمه في أي وقت طالما معروض. التعديل مش بيمسح التقييمات القديمة. |
| B8 | البايع يقدر يعلّم الطقم "اتباع" بنفسه، أو يخفيه مؤقتًا. |
| B9 | بعد 30 يوم من غير تحديث، المنصة تبعت تذكير للبايع: "لسه الطقم ده موجود؟" *(مستحسن)*. |

## ج. قواعد التقييم والتعليقات

| الرقم | القاعدة |
|---|---|
| C1 | التقييم من 1 لـ5 نجوم. |
| C2 | **مينفعش حد يحط تقييم من غير تعليق مكتوب 15 حرف على الأقل.** الزرار نفسه يفضل مقفول لحد ما الشرط يتحقق. |
| C3 | المسافات مش بتتحسب من الـ15 حرف (يعني "ممتاز        " مش هتعدي). |
| C4 | حساب واحد = تقييم واحد لكل طقم. يقدر يعدّله بس مش يضيف تاني. |
| C5 | **البايع مينفعش يقيّم طقمه.** |
| C6 | التعليق بدون تقييم مسموح (الواحد ممكن يسأل سؤال مثلًا). |
| C7 | البايع يقدر يرد على أي تعليق على طقمه. |
| C8 | متوسط تقييم الطقم بيظهر على صفحته وفي قائمة التصفح. |
| C9 | أي مستخدم يقدر يبلّغ عن تعليق مسيء *(مستحسن)*. |

## د. قواعد التفاوض على السعر

التفاوض هو إن المشتري يقول "أنا عايز أشتري بـX" والبايع يرد. ده بيحصل على **طقم معين** بين **مشتري معين** و**البايع**.

| الرقم | القاعدة |
|---|---|
| D1 | المشتري يبدأ التفاوض بإدخال **سعر مقترح**. ده اسمه **سعر البداية**. |
| D2 | سعر البداية لازم يكون أقل من سعر الطقم المعروض وأكبر من صفر. |
| D3 | البايع ليه 3 اختيارات: **يقبل** / **يرفض** / **يرد بسعر تاني** (عرض مضاد). |
| D4 | المشتري بدوره يقدر يقبل / يرفض / يرد بسعر تاني. وهكذا. |
| D5 | **التفاوض ينتهي** لما طرف يقبل (اسمه **اتفاق**) أو طرف يرفض نهائيًا، أو يعدي **7 أيام** من غير رد *(اسمه انتهى بالصمت)*. |
| D6 | **سعر النهاية** = آخر سعر اتقال قبل القبول. لو التفاوض انتهى برفض، مفيش سعر نهاية وبيتحسب كـ"فشل". |
| D7 | أقصى عدد ردود في التفاوض الواحد: **10** *(عشان ميبقاش لعب)*. |
| D8 | مشتري واحد = تفاوض واحد مفتوح على الطقم الواحد. لو اتقفل يقدر يفتح واحد جديد. |
| D9 | البايع يقدر يفاوض مع أكتر من مشتري على نفس الطقم في نفس الوقت. |
| D10 | لما الطقم يتعلّم "اتباع"، كل التفاوضات المفتوحة عليه تتقفل تلقائيًا. |
| D11 | الاتفاق على المنصة **مش ملزم** — مجرد اتفاق مبدئي والبيع بيكمل بره. المنصة بتوضح ده للطرفين. |

## هـ. قواعد المحادثات

| الرقم | القاعدة |
|---|---|
| E1 | المحادثة بتبدأ من صفحة طقم معين ("راسل البايع"). |
| E2 | مستخدمين + طقم = محادثة واحدة. لو نفس الاتنين اتكلموا على طقم تاني، دي محادثة جديدة. |
| E3 | البايع مينفعش يراسل نفسه. |
| E4 | أي مستخدم يقدر يحظر مستخدم تاني فيوقف الرسايل منه. |
| E5 | زر "اتصل" و"واتساب" بيظهروا في المحادثة وفي صفحة الطقم. الضغطة بتتسجل كحدث قياس (راجع التحليلات). |

## و. قواعد قياس الرضا

| الرقم | القاعدة |
|---|---|
| G1 | بعد ما المستخدم يكمّل حدث مهم (نشر طقم / إنهاء تفاوض / أول محادثة)، يظهرله سؤال واحد: "تجربتك على Xعفش إيه؟" من 1 لـ5 بوجوه تعبيرية. |
| G2 | السؤال يظهر **مرة كل 30 يوم** على الأكثر لنفس المستخدم عشان ميبقاش مزعج. |
| G3 | اختياري: خانة "عايز تضيف حاجة؟" نصية. |
| G4 | المستخدم يقدر يقفل السؤال من غير إجابة، وده بيتسجل كـ"تخطّى". |

## ز. استبيان ما بعد التواصل (أُضيف 12 أكتوبر)

**الفكرة:** المنصة مش بتعرف لو البيعة تمت لأنها بتكمل على واتساب أو تليفون. فلما المستخدم يضغط "واتساب" أو "اتصل" على طقم، ويرجع للمنصة بعدها، نسأله بنفسنا. ده **أهم مصدر بيانات عندنا** عن البيع الفعلي.

### متى يظهر

| الرقم | القاعدة |
|---|---|
| H1 | الاستبيان بيتربط بـ**ضغطة تواصل** معينة: مستخدم + طقم + وقت الضغطة. |
| H2 | يظهر **أول مرة يرجع المستخدم للمنصة بعد 24 ساعة على الأقل** من الضغطة. مش بيظهر في نفس الجلسة. |
| H3 | يظهر كنافذة صغيرة فوق الصفحة، فيها صورة الطقم واسمه عشان يفتكره: *"تواصلت مع البايع على [اسم الطقم] — البيعة تمت؟"* |
| H4 | 3 إجابات: **أيوه اشتريته** / **لأ متمتش** / **لسه بنتكلم**. |
| H5 | لو اختار "لسه بنتكلم": نعيد السؤال بعد 3 أيام، مرتين على الأكثر. بعد 14 يوم من الضغطة من غير إجابة نهائية → تتسجل **"مجهول"** ونبطل نسأل. |
| H6 | لو ضغط تواصل على أكتر من طقم: نسأل عن **آخر 3** بس، واحد واحد (مش كلهم في مرة). |
| H7 | المستخدم يقدر يقفل الاستبيان في أي خطوة. اللي جاوبه بيتحفظ، والباقي يتسجل "تخطّى". |
| H8 | لو نفس المستخدم ضغط تواصل على نفس الطقم أكتر من مرة، بنعتبرها ضغطة واحدة (آخر وقت). |
| H9 | لو المستخدم جاوب "أيوه اشتريته"، بنبعت للبايع إشعار لطيف: *"المشتري قال إنه اشترى [الطقم] — تعلّمه كمباع؟"* |

### المسار الأول: "أيوه اشتريته" (6 أسئلة، كلها اختيارية ما عدا الأول)

| # | السؤال | نوع الإجابة | ليه بنسأله |
|---|---|---|---|
| ب1 | اشتريته بكام؟ | رقم بالجنيه | نقارنه بالسعر المعروض وسعر التفاوض → نعرف الفرق بين "اللي اتقال على المنصة" و"اللي حصل فعلًا". |
| ب2 | دفعت تكاليف إضافية (نقل / فك وتركيب / غيره)؟ | لأ / أيوه → كام؟ + إيه نوعها (اختيارات) | نعرف التكلفة الحقيقية الكاملة، وممكن بعدين نضيف "السعر شامل النقل؟" في الإعلان. |
| ب3 | كان فيه مبالغ مكانتش متفق عليها قبل الاستلام؟ | لأ / أيوه → كام؟ + إيه هي (نص قصير) | **إنذار ثقة.** لو بايع بيتكرر معاه ده، بيظهرلك في الداشبورد (راجع قرار 23). |
| ب4 | حالة المنتج لما استلمته عجبتك؟ | 1–5 نجوم + اختياري: "أحسن / زي / أسوأ من الصور" | نقيس صدق الإعلانات. "أسوأ من الصور" بتكرار = مشكلة في البايع أو في شرط الصور. |
| ب5 | اضطريت تصرف عليه عشان تحسّنه (تنجيد / دهان / إصلاح)؟ | لأ / أيوه → كام تقريبًا؟ | نعرف "التكلفة الخفية" للعفش المستعمل، ونقدر نوضحها للمشترين الجداد. |
| ب6 | المنصة كانت مفيدة ليك؟ | أيوه / لأ | راجع القسم المشترك تحت. |

### المسار التاني: "لأ متمتش" (3 أسئلة)

| # | السؤال | نوع الإجابة | ليه بنسأله |
|---|---|---|---|
| ج1 | ليه متمتش؟ (اختار كل اللي ينطبق) | اختيارات متعددة: البايع مردش / البايع رد متأخر / السعر مش مناسب واتفقناش / الحالة أسوأ من الصور / المواصفات مختلفة عن الوصف / اتباع لحد تاني قبلي / بعيد عني ومفيش نقل / غيّرت رأيي / البايع مش محترم / غير ذلك (نص) | ده **أهم سؤال في الاستبيان كله**. توزيع الإجابات بيقولك فين المشكلة: في البايعين؟ في الصور؟ في السعر؟ في الجغرافيا؟ |
| ج2 | لسه بتدور على عفش شبهه؟ | أيوه / لأ | لو أيوه، ممكن نعرضله أطقم مشابهة فورًا. بيقيس كمان لو المنصة لسه ليها قيمة عنده. |
| ج3 | المنصة كانت مفيدة ليك؟ | أيوه / لأ | راجع القسم المشترك. |

### القسم المشترك: "المنصة كانت مفيدة؟"

| الإجابة | السؤال التالي | نوع الإجابة |
|---|---|---|
| **أيوه** | إيه اللي كان مفيد؟ | اختيارات متعددة: الصور واضحة / السعر واضح / التفاوض / المحادثة / التقييمات / سهولة التواصل / لقيت اللي عايزه بسرعة / غير ذلك (نص) |
| **لأ** | إزاي تنصحنا نحسّن؟ | نص حر (اختياري) + اختيارات: أطقم قليلة / البايعين مش بيردوا / البحث صعب / الصور مش كفاية / غير ذلك |

### قواعد عامة للاستبيان

| الرقم | القاعدة |
|---|---|
| H10 | كل سؤال في شاشة لوحده، مع شريط تقدّم ("3 من 6") عشان المستخدم يعرف فاضل قد إيه. |
| H11 | الاستبيان كله لازم يخلص في **أقل من دقيقة**. مفيش سؤال إجابته نص إجباري. |
| H12 | إجابات ب3 و"البايع مش محترم" و"الحالة أسوأ من الصور" **مش بتتعرض علنًا** — لصاحب المنصة بس. |
| H13 | إجابات الاستبيان **مش بتأثر** على التقييم بالنجوم اللي على الطقم (ده نظام منفصل). |
| H14 | لو البايع علّم الطقم "اتباع" **قبل** ما المشتري يجاوب، لسه بنسأل المشتري (عشان نتأكد إنه هو اللي اشترى). |
| H15 | البايع لما يعلّم "اتباع" يظهرله 3 أسئلة: اتباع بكام؟ / المشتري كان محترم ومفيش مشاكل؟ (أيوه/لأ + نص) / المنصة ساعدتك؟ (أيوه/لأ). |
