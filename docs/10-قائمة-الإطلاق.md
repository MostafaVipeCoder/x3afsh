## ب. محتاج إيدك قبل الإطلاق (بالترتيب)

### ب-1. الرفع على GitHub Pages ✅
الموقع منشور يوم 14 أكتوبر على `https://mostafavipecoder.github.io/x3afsh/`. أي تعديل يترفع على الفرع main بينزل على الموقع لوحده خلال دقيقة.

### ب-2. تسجيل الرابط في Supabase — **من غيره الدخول بجوجل مش هيرجّع المستخدم للموقع**
في [لوحة Supabase ← Authentication ← URL Configuration](https://supabase.com/dashboard/project/idxjtijqhpencivsoigw/auth/url-configuration):
- **Site URL:** رابط الموقع (مثلًا `https://USERNAME.github.io/x3afsh/`)
- **Redirect URLs:** نفس الرابط، وكمان `http://localhost:5173/` للتجربة المحلية.

### ب-3. تفعيل الدخول بجوجل — **من غيره زرار جوجل هيطلع رسالة "مش متفعّل"**
محتاج حساب Google Cloud (مجاني):
1. افتح [Google Cloud Console ← Credentials](https://console.cloud.google.com/apis/credentials) واعمل مشروع جديد اسمه X3afsh.
2. **Create Credentials ← OAuth client ID ← Web application.**
3. في **Authorized redirect URIs** حط بالظبط:
   ```
   https://idxjtijqhpencivsoigw.supabase.co/auth/v1/callback
   ```
4. انسخ **Client ID** و**Client Secret**.
5. في [Supabase ← Authentication ← Providers ← Google](https://supabase.com/dashboard/project/idxjtijqhpencivsoigw/auth/providers): فعّل، والصق الاتنين، واحفظ.
6. أول مرة جوجل هيطلب منك "شاشة موافقة" (OAuth consent screen): حط اسم المنصة ورابط الخصوصية `https://USERNAME.github.io/x3afsh/#/privacy`.

### ب-4. مزوّد SMS — **من غيره الدخول بالموبايل شغال بالأرقام التجريبية بس**
اختار من [ملف 11](11-مزودو-SMS.md)، واعمل حساب، وابعتلي مفتاح الربط. لحد ما تختار، فعّل الأرقام التجريبية (ملف 09 قسم 3) عشان تجرّب أنت وفريقك.

### ب-5. PostHog ✅
اتفعّل يوم 14 أكتوبر (منطقة أوروبا). الموقع المنشور بيبعت الأحداث فعليًا، وتسجيل الجلسات شغال كمان. ابدأ ببناء القمع الخمسة من ملف 04 جوه PostHog لما ييجي أول زوار.

## ج. قرارات صغيرة محتاجة رأيك

### ج-1. الأرقام التجريبية لازم تتشال قبل الإطلاق العام
الرقم التجريبي بكود ثابت = أي حد يعرفه يقدر يدخل بيه. بعد ما مزوّد الـSMS يشتغل، امسحهم من لوحة Supabase.

### ج-2. هل الدخول بجوجل يفضل بعد ما الـSMS يشتغل؟
- **أيوه (الاقتراح):** أسهل للناس وبيوفر فلوس SMS. العيب إن رقم الموبايل بيبقى غير مؤكد.
- **لأ:** كل الحسابات برقم مؤكد، بس كل تسجيل بيكلف رسالة.
- **حل وسط ممكن بعدين:** اللي دخل بجوجل نطلب منه يأكد رقمه بكود مرة واحدة قبل أول طقم ينشره.

### ج-3. إيميل جوجل بتاعك ✅
اتضاف يوم 12 أكتوبر. أول دخول بجوجل بالإيميل ده هيفتح لوحة التحكم مباشرة.

**ملاحظة:** الدخول بجوجل بيعمل حساب منفصل عن حساب الموبايل (الاتنين أدمن). لو حابب يبقوا حساب واحد قوللي، بس مفيش داعي طالما الاتنين بيفتحوا نفس لوحة التحكم.

### ج-4. اسم المنصة في جوجل
لما تعمل شاشة الموافقة في Google Cloud، الاسم اللي هتكتبه هو اللي الناس هتشوفه: "Xعفش" ولا "X3afsh"؟
